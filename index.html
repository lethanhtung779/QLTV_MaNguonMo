ỨNG DỤNG PHP + MYSQL

Hãy khởi động thư viện.

Bản giao diện HTML cũ đã được ngừng sử dụng. Hệ thống chính cần PHP 8.2+, PDO MySQL và MySQL/MariaDB để lưu dữ liệu thật.

php -S 127.0.0.1:8000 -t public public/index.php

Sau khi cấu hình .env, chạy php database/setup.php và php database/seed.php, rồi mở http://127.0.0.1:8000.
